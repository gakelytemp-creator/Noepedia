## 2. მოდალური ცენტრები

ცენტრი არის სრული ორგანო ერთი მოდალობისთვის.

მისი მინიმალური ნაწილებია:
- ამომცნობი;
- სინთეზატორი;
- სეგმენტაციის წესი;
- ნიმუშების საცავი;
- საკუთარი სპეციალიზებული დამმუშავებელი;
- ცნებების ველზე მისამართების კავშირი.

ცენტრი რეალობასთან კონტაქტის ერთ ფორმას ამუშავებს.

ტექსტის ცენტრი, მხედველობის ცენტრი და სმენის ცენტრი სხვადასხვა მასალას იღებენ,
მაგრამ შეიძლება ერთსა და იმავე ცნებაზე მიუთითებდნენ.

### უკუსინთეზი

ცენტრის სინთეზატორი შეიძლება გაეშვას არა გარედან მიღებული ნაკადით, არამედ
ცნებების ველიდან.

~~~text
ცნება → ცენტრის სინთეზატორი → მოდალური შიდა ნიმუში
~~~

ასეთი შედეგი აუცილებლად უნდა დარჩეს მონიშნული როგორც **სინთეზირებული** და არა
როგორც გარედან მიღებული.

ჰალუცინაციის ამ მექანიკურ მოდელს ამჟამად აქვს სტატუსი **WORKING HYPOTHESIS**.

## 3. ცნებების ველი

ცნებების ველი არის საერთო მისამართიანი ხერხემალი.

იგი ინახავს:
- ცნებებს;
- S/P/O ნომინაციებს;
- ტრიპლეტებს;
- დესკრიფციებს;
- ქსელებისა და წესების სახელურებს;
- წარმომავლობას;
- დროსა და კონტექსტს;
- OPEN-ს;
- ვერსიებსა და ისტორიას;
- semiotic cut / certificate ინფორმაციას.

პრედიკატიც ცნებაა. წესიც შეიძლება ცნება იყოს. ჟურნალის ჩანაწერიც ველშია.

ველი **არ არის თვითონ აზროვნება**.

მისი ფუნქციაა სტრუქტურის შენახვა, მისამართიანობა, რეკონსტრუქცია და სხვადასხვა
ოპერატორისთვის ერთი საერთო მასალის მიწოდება.

## 4. კონსტრუქციული სამყარო

კონსტრუქციული სამყარო არის არა ერთი ცხრილი და არა ერთი პროცესი.

იგი არის კანონებით წარმოქმნილი შესაძლებლობათა სივრცე, რომელშიც დროებითი სცენები
და მონახაზები იგება.

აქ ერთმანეთს უნდა გავუცალკეოთ:

- **შესაძლებლობათა სივრცე** — კანონებით დაშვებული კონფიგურაციებისა და გადასვლების სივრცე;
- **სცენა** — კონკრეტული მიმდინარე ამოცანის აგებული მდგომარეობა;
- **მონახაზი** — შესაძლო ცვლილება commit-ის გარეშე;
- **კონსტრუქციის ცენტრი** — ორგანო/სერვისი, რომელიც ამ სივრცეში აგებასა და
  შემოწმებას ახორციელებს;
- **დემონი** — ოპერატორის სამუშაო სახელი, რომელიც კანონიერ გზას მიჰყვება,
  შეუსაბამობაზე ჩერდება და OPEN-ს არ ფარავს.

კონსტრუქციის ცენტრი **არ არის თვითონ შესაძლებლობათა სივრცე**.

## 5. დემონის მინიმალური ფუნქცია

მიმდინარე სურათში დემონის ბირთვი არ არის „ჭკვიანი პასუხის გენერაცია“.

მისი მინიმალური ფუნქციაა:

~~~text
მოთხოვნა
→ აიღე შესაბამისი სცენა
→ გაავრცელე უკვე არსებული შეზღუდვები
→ სადაც შეიძლება — ააგე
→ სადაც ვერ აგებ — გაჩერდი
→ დაარეგისტრირე მიზეზი / OPEN
→ საჭიროებისას დაადეტალე ან გაიყავი
~~~

სოკრატული თვისება სწორედ გაჩერებაა:

> **ცხოველი ჩერდება, როცა ვერ ჭამს; სოკრატული ოპერატორი — როცა ვერ აგებს.**

## 6. ანალიზი და სინთეზი

კონსტრუქციის ერთ-ერთი ძირითადი წყვილია:

~~~text
ANALYSIS  ⇄  SYNTHESIS
~~~

თუ რთული ობიექტი იშლება ნაბიჯებად, აღდგენისას ნაბიჯები შებრუნებული წესით უნდა
დაწყვილდეს.

მნიშვნელოვანია არა მხოლოდ ნაწილების შენახვა, არამედ **კავშირების შენახვაც**.

ამიტომ ტრიპლეტები მხოლოდ აღწერის ფორმა კი არა, რეკონსტრუქციის მასალაა.

## 7. სამუშაო მოძრაობა

მიმდინარე ზოგადი მარყუჟია:

~~~text
RULES
→ SPACE
→ SCENE
→ BUILD
→ PASS / BLOCKED
→ QUESTION / REBUILD / REOPEN
→ DRAFT
→ COMMIT or KEEP-INTERNAL
~~~

PASS ნიშნავს შიდა კანონებთან თავსებადობას.

COMMIT ნიშნავს შიდა შედეგის გარეთა მოქმედებად, კითხვად, გაზომვად ან ახალ persistent
ჩანაწერად გადატანას.

### მომავლისთვის დატოვებული მონახაზი — ხაფანგი, Kairos და წყვეტა

შიდა კონსტრუქცია ყოველთვის დაუყოვნებელ მოქმედებად არ უნდა გადაიქცეს.

სისტემას შეუძლია წინასწარ ააგოს **მომავალი შესაფერისი სიტუაცია** და გარეთ გაიტანოს
არა თვითონ მოქმედება, არამედ მისი ამომცნობი პირობა:

~~~text
შიდა სცენა
→ მომავალი სიტუაციის პირობა
→ TRAP commit
→ რეალური სამყარო მოძრაობს
→ პირობა შედგა
→ KAIROS
→ INTERRUPT
→ resume / action / question
~~~

აქ **Kairos** არ არის Chronos-ის ალტერნატიული საათი. Chronos არის ერთ-ერთი შესაძლო
კოორდინატი — „17:00“, „ხვალ“, „ორი საათის შემდეგ“. Kairos არის ის მოვლენა, როცა
მოქმედებისთვის წინასწარ აღწერილი სიტუაცია **მწიფდება**.

ხაფანგი შეიძლება მიებას არა მხოლოდ დროს, არამედ:

- ადგილს;
- ნივთს ან კონკრეტულ ცნებას;
- ადამიანს/აგენტს;
- ველის მდგომარეობას;
- ცოდნის კონდიციას;
- რამდენიმე პირობის ერთობლიობას.

ამიტომ **ხაფანგი არის Kairos-ის წინასწარ აგებული ამომცნობი**, ხოლო **წყვეტა** —
მისი კვრის მოვლენა.

ამ ფორმით ინტერრაპტების სისტემა ხდება ორი სამყაროს სახსარი: იდეალურ სამყაროში
ვაგებთ მომავალ სიტუაციას, რეალურ სამყაროში კი მხოლოდ მის დადგომას ველოდებით.
ყოველ წამს ხელახალი აზროვნება საჭირო აღარ არის.

## 8. BLOCKED-ის სახეები

BLOCKED ერთ რამეს არ ნიშნავს.

მინიმუმ საჭიროა სამი განსხვავება:

- **RULE_BLOCKED** — მოქმედი კანონი კრძალავს გადასვლას;
- **STRUCTURE_OPEN** — საჭირო ცნება, ბმა ან შუალედური სტრუქტურა ჯერ არ გვაქვს;
- **BRIDGE_LIMIT** — შიდა გზა აგებადია, მაგრამ რეალობასთან შესაბამისობის სერტიფიკატი
  აქ აღარ ვრცელდება.

მეოთხე შესაძლო შემთხვევაა **SEARCH_OPEN** — გზა შეიძლება არსებობდეს, მაგრამ
ოპერატორმა ჯერ ვერ იპოვა. ეს ჯერ OPEN-ია და არა შეუძლებლობის მტკიცება.

## 9. პლასტები და დემონების კოჰორტა — WORKING HYPOTHESIS

შიდა კონსტრუქციული სამყარო შეიძლება ერთდროულად რამდენიმე პლასტში არსებობდეს.

სამუშაო ჰიპოთეზაა:
- თითო პლასტს აქვს თავისი ჰორიზონტალური კანონები;
- პლასტებს ვერტიკალური შედგება/მოთხოვნა/შესაძლებლობის კავშირები აერთიანებს;
- ერთ პლასტში კანონიერი ნაბიჯი შეიძლება მეორეში ვერ აიგოს;
- ეს აცდენა უნდა გახდეს მისამართიანი OPEN და არა ჩუმი ჩახშობა.

„დემონების კოჰორტა“ არის ამ ფუნქციის სამუშაო მეტაფორა და ჯერ არა საბოლოო
იმპლემენტაციის მოთხოვნა.

## 10. არსებული კომპონენტების ადგილი

მიმდინარე ხედვაში:

- `core/lexicon/` — ტექსტის ცენტრისა და ცნებების ველის საზღვრის რესურსია;
- `core/cell/cell_v0.py` — უცნობი ტექსტური პრედიკატების detector/ingest prototype-ია,
  არა სრული მოაზროვნე უჯრედი;
- `core/lexicon/fundamentals.md` — შიდა სამყაროს შესაძლო ფუნდამენტური კანონების
  კანდიდატური ინვენტარია;
- `noe_kernel*.py` — ველის ფიზიკური განლაგების ისტორიული/კანდიდატური იმპლემენტაციებია;
- revision subsystem — ერთი სპეციალიზებული პროცედურული ორგანოა;
- LLM — სემანტიკური boundary adapter-ია და შეიძლება ასევე იყოს გენერაციული დამხმარე,
  მაგრამ მისი ტექსტი თავისთავად field truth არ არის.

დეტალური გადანაწილება იხ. [MIGRATION_MAP.md](MIGRATION_MAP.md).

## 11. არქიტექტურული გუშაგი

ახალი კომპონენტი მხოლოდ იმიტომ არ იბადება, რომ ახალი მეტაფორა გაჩნდა.

ნებისმიერ ახალ ბლოკზე უნდა შეგვეძლოს პასუხი:

1. რომელ სართულს ეკუთვნის?
2. რა მასალას იღებს?
3. რას აბრუნებს?
4. რა კანონით ჩერდება?
5. რას წერს ველში?
6. რა არის მისი provenance?
7. როდის სჭირდება რეალობასთან დაბრუნება?

თუ ამას ვერ ვპასუხობთ, კომპონენტი ჯერ OPEN-ია.
