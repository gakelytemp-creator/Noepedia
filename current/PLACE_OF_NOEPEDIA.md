# PLACE_OF_NOEPEDIA — სისტემის ადგილი სამყაროში

## 1. Noepedia არ არის მესამე სამყარო

Noepedia არ უნდა ავურიოთ არც რეალურ სამყაროში და არც იდეალურ სამყაროში.

იგი არის **ინფრასტრუქტურა მათ საზღვარზე**.

მისი საქმეა:
- რეალური კონტაქტების კვალის მისამართიანად შენახვა;
- სხვადასხვა მოდალობის პროექციების ერთ ცნებებთან შეკვრა;
- წარმომავლობის, დროის, სტატუსისა და გაურკვევლობის შენარჩუნება;
- შიდა კონსტრუქციისთვის კანონებისა და მასალის მიწოდება;
- შიგნით აგებულისა და გარეთ დამოწმებულის ერთმანეთში არევა არ დაუშვას.

## 2. საზღვრისპირა საწყობი

კარგი სამუშაო მეტაფორაა:

> **Noepedia არის დეკლარაციებიანი საზღვრისპირა საწყობი.**

საწყობში შესულ მასალას უნდა ახლდეს მინიმუმ:
- რა არის მისამართი;
- საიდან მოვიდა;
- როდის მოვიდა;
- რა ტიპის ჩანაწერია;
- რა სტატუსი აქვს;
- რა არის პირდაპირი კონტაქტი და რა — შიდა კონსტრუქცია;
- სად მთავრდება მისი დამოწმებული მოქმედების არე.

ამიტომ provenance დეკორაცია არაა. იგი საბაჟო დეკლარაციაა.

## 3. ორი მიმართულება

Noepedia-ს საზღვარზე მოძრაობა ორმხრივია.

### რეალური → შიდა

~~~text
რეალური მოვლენა / სიგნალი
→ ცენტრი
→ ამოცნობა / სეგმენტაცია
→ ცნება / ბმა
→ წარმომავლობის ჩანაწერი
→ შიდა სამყაროს განახლება
~~~

ეს არის **განახლება**.

### შიდა → რეალური

~~~text
მონახაზი / კონსტრუქცია
→ შიდა აგებითი შემოწმება
→ საჭირო semiotic cut / certificate
→ მოქმედება / გაზომვა / წარმოება / კითხვა
→ რეალური შედეგი
→ ახალი კონტაქტი
~~~

ეს არის **commit** ფართო მნიშვნელობით.

შიდა აგებულის გარეთ გატანა არ ნიშნავს, რომ იგი წინასწარ ჭეშმარიტი იყო.
რეალური შედეგი შეიძლება:
- დაემთხვეს;
- ნაწილობრივ დაემთხვეს;
- უარყოს;
- ან გახსნას ახალი OPEN.

### გადადებული commit — მომავალი სიტუაციის დაჭერა

შიდა კონსტრუქცია ზოგჯერ გარეთ გადის არა როგორც დაუყოვნებელი მოქმედება, არამედ
როგორც **მომავალი პირობის დამჭერი ხაფანგი**.

~~~text
„როცა ეს სიტუაცია შედგება“
→ trap
→ რეალური სამყაროს ლოდინი
→ Kairos
→ interrupt
→ მოქმედების/კითხვის/თრედის resume
~~~

ამიტომ საზღვარი მხოლოდ „ახლა გავაკეთო თუ არა“-ს არ ემსახურება. მას შეუძლია
იდეალური სამყაროდან რეალურ მომავალში დატოვოს მისამართიანი პირობა და გააღვიძოს
შიდა პროცესი მაშინ, როცა საჭირო კონტექსტი ნამდვილად დადგება.

Chronos ამ პირობის ერთი შესაძლო ნაწილია; Kairos კი თვითონ შესაფერისი სიტუაციის
დადგომაა.

## 4. ორი საათი

რეალური და შიდა სამყარო ერთსა და იმავე სიჩქარით არ იცვლება.

ხანდახან რეალური წინ მიდის და შიდა აღწერა ძველდება.

ხანდახან შიდა წინ მიდის და აგებს იმას, რაც რეალობაში ჯერ არ განხორციელებულა.

ამიტომ ჩანაწერებს სჭირდება მინიმუმ ორი განსხვავებული სტატუსური კითხვა:

- **ბოლოს როდის დამოწმდა გარეთ?**
- **ეს უკვე გარეთაა თუ ჯერ მხოლოდ შიგნით?**

ამ ორი ნიშნულის დაკარგვა სხვადასხვა კლასის შეცდომას ქმნის.

## 5. საერთო მეხსიერება, არა საერთო მითი

Noepedia-ს ღირებულება ის არ არის, რომ ერთ მოდელს ერთი დიდი ისტორია დაუგროვოს.

მისი ღირებულებაა, რომ სხვადასხვა ადამიანი, მოდელი, სენსორი და პროცედურა ერთსა და იმავე
მისამართიან სტრუქტურაზე მუშაობდეს ისე, რომ:
- წყაროები არ აირიოს;
- უთანხმოება არ დაიმალოს;
- OPEN არ შეივსოს ყველაზე დამაჯერებელი ტექსტით;
- შიდა კონსტრუქცია რეალურ კონტაქტად არ გასაღდეს.
