## 3. კონსტრუქციული ოპერატორი

### OPEN-D1 — დემონის ერთეული
ერთი ზოგადი ოპერატორი საკმარისია თუ თითო პლასტს თავისი ადგილობრივი ოპერატორი სჭირდება?

### OPEN-D2 — „ყველაზე ცოტა უცნობი“

სამუშაო წესი უკვე გვაქვს, მაგრამ კითხვა დახურული არ არის.

სცენა იყოს `S`, მასში ღია ცვლადები `x ∈ X_S`.

თითოეულ `x`-ს აქვს:
- `U(x)` — დასაშვები მნიშვნელობების სამყარო, დროშით `closed | open`;
- `C_S(x)` — აქტიური შეზღუდვები, რომლებიც შეიძლება ერთდროულად რამდენიმე ცვლადსაც
  აკავშირებდეს.

კანდიდატები ერთჯერადი ფილტრით კი არა, შეზღუდვების გავრცელების შემდეგ ითვლება:

~~~text
Cand_S(x)    = { v ∈ U(x) | v თავსებადია C_S(x)-თან, გავრცელების შემდეგ }
Freedom_S(x) = |Cand_S(x)|
x*           = argmin Freedom_S(x)
~~~

„სიმკვრივე“ ცალკე საზომად ჯერ არ შემოგვაქვს: ნორმალიზებული ფორმა ხშირად თვითონ
`U(x)`-ის ზომას ითხოვს, ხოლო `U` შესაძლოა OPEN იყოს.

`x*`-ის მიხედვით სამუშაო ქცევა:

| Freedom(x*) | U(x*) | მოქმედება |
|---|---|---|
| 1 | ნებისმიერი | **გავრცელება** — დააყენე, provenance ჩაწერე, თავიდან დაიწყე |
| ≥ 2 | ნებისმიერი | **გაყოფა** — თითო კანდიდატზე „X / არა-X“ |
| 0 | closed | **CONFLICT** — ამ ტოტში ჰიპოთეზა უარყოფილია; ტოტი იკვეთება |
| 0 | open | **STRUCTURE_OPEN / SEARCH_OPEN** — არა CONFLICT |

ძირითადი რიგი:

~~~text
1. თუ პლასტთაშორისი აცდენაა → ღრიალის ჩანაწერი, არა მოკვეთა
2. გაავრცელე შეზღუდვები
3. x* = argmin Freedom
4. გავრცელება / გაყოფა / CONFLICT / STRUCTURE_OPEN
~~~

თანაბარი Freedom-ის tie-break ჯერ OPEN-ია. ვერტიკალური წნეხი შეიძლება ჩაიწეროს
დიაგნოსტიკად, მაგრამ არჩევის წესად ჯერ არ არის დასაბუთებული.

დატოტვის ლიმიტი რჩება OPEN-D4-ში.

**ანკერი / provenance:** ეს ევრისტიკა ახლოს დგას CSP-ის MRV / fail-first წესთან;
`Freedom = 1` შემთხვევა — unit propagation-ის ტიპის ნაბიჯია.

**დახურვის პირობა:** წესი უნდა გაიაროს მინიმუმ სამ აგებულ მაგალითს:
- პატარა სუდოკუ, დახურული `U`;
- წინდა → ფეხსაცმელი → ქუდი, მრავალცვლადიანი რიგის შეზღუდვებით;
- open-`U` შემთხვევა, სადაც `Freedom = 0` უნდა ნიშნავდეს STRUCTURE_OPEN-ს და არა CONFLICT-ს.

**წყარო:** Grok-ის მონახაზი, Claude-ის შერჩევა/დაზუსტება, 2026-10-14.

## 4. პლასტები

### OPEN-P1 — პლასტის განსაზღვრება

### OPEN-P3 — ღრიალი

ერთი საზღვარი უკვე მკაფიოა:

> **ღრიალი ≠ CONFLICT.**

**CONFLICT** გაყოფის კონკრეტულ ტოტში ნიშნავს, რომ ამ ტოტის ჰიპოთეზა უარყოფილია;
ტოტის მოკვეთა სწორია.

**ღრიალი** კი პლასტთაშორისი აცდენაა: ერთ პლასტში ნაბიჯი კანონიერია, მეზობელში კი
იგივე ნაბიჯი ვერ იკვრება. იგი არ იკვეთება ავტომატურად — იწერება მისამართიან OPEN-ად,
მონახაზში იკვლევა და, თუ შესაძლებელია, შემოვლითი გზა ეძებება.

სამუშაოდ ორი სახე გამოიკვეთა:

1. **კანონთა აცდენა** — ორივე პლასტში სტრუქტურა არსებობს; თითოეულში ცალ-ცალკე
   `Cand ≠ ∅`, მაგრამ მათი ერთობლივი მოთხოვნებით `Cand = ∅`.
2. **სტრუქტურის ნაკლი** — ერთ-ერთ პლასტს ამ ნაბიჯისთვის საჭირო ცნება, ბმა ან კანონი
   საერთოდ არ გააჩნია.

მინიმალური მისამართიანი ჩანაწერი უნდა ინახავდეს:
- რომელი პლასტებია ჩართული;
- რომელი ნაბიჯი გაჩერდა;
- რომელი სახეა: კანონთა აცდენა თუ სტრუქტურის ნაკლი;
- რომელი კანონები/მოთხოვნები ვერ თანხმდება;
- რომელ მონახაზში მოხდა;
- მიმდინარე სტატუსი.

**ღია რჩება:** ამ ჩანაწერის საბოლოო ფორმალური სქემა და ზუსტი წესი, როდის ხდება
ღრიალი REOPEN-ის მიზეზი.

**წყარო:** Grok-ის მონახაზი, Claude-ის შერჩევა/დაზუსტება, 2026-10-14.
