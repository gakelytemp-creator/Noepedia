# Experiment 037 — Third Independent Knowledge-Revision Loop

Experiment 037 tests the Noepedia revision architecture on a third relation family.

Relation family:
H1 state vs Reservoirs state.

This experiment does not use DV_eletric, Motor_current, TP2, or TP3 in the rule under test.

Windows:
- discovery = rows 650,001..655,000
- confirmation = rows 700,001..705,000

The discovery window selects one candidate from a frozen finite temporal family.
The selected candidate is then frozen and tested on untouched confirmation data through the frozen Noepedia evaluator.
