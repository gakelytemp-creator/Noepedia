# Experiment 069 — Promotion Bottleneck / Null-Coverage Audit

Experiment class: DIAGNOSTIC / PIPELINE AUDIT

Purpose:
explain why Experiment 068 produced zero promotions without changing Experiment 068 or reinterpreting its preregistered scientific result.

Experiment 068 remains closed as:
`NO_REAL_PROMOTION_AND_SHUFFLED_ZERO`

This experiment asks:
- how many real and shuffled pairs stopped because evidence was insufficient;
- how many stopped because the selected temporal optimum hit a search boundary;
- how many stopped because a null selected by `nulls.py` had no metric supplied by the selected evaluator;
- whether this missing-null condition is symmetric between real and shuffled data.

No promotion gate, feature threshold, null rule, or search range is changed in Experiment 069.
