# უჯრედი v0 — სპეციფიკაცია
*(core/cell/ · 2026-10-12 · მინიმალური ცოცხალი უჯრედი: ჭამს ტექსტს, აგროვებს კითხვებს,
გვაწყვეტინებს და გვეკითხება. ტვინი არ აქვს და არ სჭირდება — სიცოცხლე ტვინამდე.)*

---

## 1. რას ვამოწმებთ

ერთი წესი: **უცოდინრობაზე დადებული ხაფანგი საკმარისია, რომ სისტემამ შიგნიდან
განვითარება დაიწყოს.** უჯრედი არაფერს იგონებს — მხოლოდ ინელებს, რაც ლექსიკონით
ინელდება, და დანარჩენს კითხვად აგროვებს. როცა კითხვა ზღურბლს გადააჭარბებს,
უჯრედი წყვეტს ჩვენს ნაკადს და გვეკითხება. პასუხი ლექსიკონში ეწერება →
შემდეგი ტექსტი უფრო ღრმად ინელდება → კითხვები ცოტავდება და ღრმავდება.
გაჯერების მრუდი = ზრდის მრუდი.

## 3. კითხვის ტიპები (დეტერმინისტულად ამოცნობადი)

| ტიპი | ტრიგერი | კითხვის ფორმა |
|---|---|---|
| Q1 უცნობი პრედიკატი | ზმნა ლექსიკონში არ არის | „რა არის X? რომელი ქსელის შტეკერია, რა ბუდეები აქვს?" |
| Q2 შეუვსებელი აუცილებელი ბუდე | პრედიკატი დაჯდა, ! ბუდე ცარიელია | „X-ს Y აკლია: ვინ/ვის/რაზე?" |
| Q3 უპატრონო მითითება | „ის ქალი", „იმ დღეს" — წინამორბედი ვერ მოიძებნა | „რომელ X-ზეა ლაპარაკი?" |
| Q4 წინააღმდეგობა | x და არა(x) ორივე ჩაჯდა ერთ ჩარჩოში | „x მართალია თუ არა(x)? წყაროები: …" |
| Q5 ტიპის დარღვევა | ბუდეში უკანონო სტუმარი claim-ჩარჩოში | „X ბუდეში Y ზის — მეტაფორაა თუ შეცდომა?" |

ყოველი კითხვა ტრიპლეტებად იწერება: addr · ტიპი · სად გაჩნდა (ტექსტი, წინადადება) ·
რამდენჯერ · სტატუსი (OPEN / ნაპასუხები / ვცადე-ვერა).

## 4. ხაფანგის წესი (კუტურიეს ზღურბლი)

- ერთი და იგივე უცნობი X მეორედ შეგვხვდა (count ≥ 2) → წყვეტა
- Q4 წინააღმდეგობა → დაუყოვნებელი წყვეტა (ყველაზე ძლიერი)
- ტექსტი დასრულდა და OPEN კითხვები დარჩა → შემაჯამებელი წყვეტა: „აი რა ვერ მოვინელე"
- ზღურბლამდე კითხვა ჩუმად გროვდება — უჯრედი ყოველ სიტყვაზე არ წრიპინებს

## 5. ზეიგარნიკის მეხსიერება

კითხვები ტექსტებს შორის **რჩება**. ახალი ტექსტი ჯერ ძველ OPEN კითხვებს ეჯახება:
თუ ახალმა ტექსტმა ძველი კითხვა დახურა (უცნობი სიტყვა კონტექსტით გაირკვა) —
უჯრედი ამას გვატყობინებს თვითონ: „X გავიგე Y ტექსტიდან, დაადასტურე".
დადასტურება = ჩანაწერი ლექსიკონში ორი ხელმოწერით (cell + ადამიანი).

## 6. დალუქული acceptance-ტესტი

**ტესტი A (პირველი ტირილი):** ვაჭმევთ „ვანო და ნიკო და ასანთი"-ს 77-იანი ლექსიკონით.
მოსალოდნელი: Q1-ები ≈ {ეძება, გაწოდება, მოწონება, წერა(მისწერა), გაკვრა, ჩაქრობა, ხურვა}
— ის 7, რაც 2026-10-12-ს ხელით ვიპოვეთ. პასუხი წინასწარ დალუქულია, დიფერენტი იზომება.

**ტესტი B (ზრდა):** ვპასუხობთ 7-ვეს → იმავე ტექსტს მეორედ ვაჭმევთ.
მოსალოდნელი: Q1 = 0, რჩება მხოლოდ Q2/Q3 ნაშთი. უჯრედი გაიზარდა.

**ტესტი C (ჟანრის ნახტომი):** კომპრესორის ინსტრუქცია. მოსალოდნელი: Q1 ≈ 16,
ახალი ატომის მოთხოვნა = 0 (ფსონი). Q5 არცერთი (ინსტრუქციას მეტაფორა არ აქვს).

## 7. რა არ შედის v0-ში (განზრახ)

- პასუხების თვითონ მოგონება — უჯრედი არ იგონებს, ეკითხება
- საჭმლის არჩევა — ვაჭმევთ ჩვენ (v1: თვითონ ითხოვს „კიდევ ამ ავტორის")

## 8. ფიზიკა

Python, ერთი ფაილი (cell_v0.py), SQLite ან მეხსიერების დიქტები — layout-ის კონფლიქტი
(§გ.11) აქ არ წყდება, უჯრედი ლოგიკურ სივრცეზე წერს. ლექსიკონი იკითხება
