## III. ნიმუშები ტექსტიდან, ბოლომდე დაშლილი

**„ორივეს გაახსენდა, რომ დღეს დილას მიესალმნენ ერთმანეთს"**
```
e1 = F11: მისალმება(ვანო↔ნიკო)          ← დილის მოვლენა-ატომი
F9(ვანო → e1)   F9(ნიკო → e1)           ← ორი ცოდნის ბმა
F1(e1 წინ ახლაზე)                        ← „დღეს დილას" = იმავე ჩარჩოში, უკან
```

**„ნიკომ გარტყმითვე უპასუხა"**
```
e8 = F11: გარტყმა(ვანო→ნიკო)
e9 = F11: გარტყმა(ნიკო→ვანო)
F1(e9 შემდეგ e8)
F5(e9.მანერა იგივე e8.მანერა)            ← „-ვე" სუფიქსი = ერთი F5-ბმა!
F6(e8 იწვევს e9)
```

**„კარადაში პური არ იყო"**
```
F7( F2-შიგნით(პური, კარადა) )            ← უარყოფა ჩადგმის ბმაზე
F1: ინტერვალში [შინ-მისვლა, მაღაზია]
```

**„ყველაფერი რიგზე იქნებოდა, ნიკო უხეშად რომ არ ელაპარაკებოდეს"**
```
W′ = F10(შესაძლო სამყარო)
W′-ში: F7(უხეშობის ნიმუში-კვანძი)        ← ერთი ბმა მოხსნილი
F6(→ „ყველაფერი რიგზე")                  ← შედეგი გადათვლილი W′-ში
```

**„ერთხელ ვანოს ეძინა"** (მოსავლის ჭერი)
```
ჩარჩო: ერთხელ_k (ახალი tbl; მშობელი დღე — OPEN)
მატარებელი: ვისი=ვანო, რა=ძილი(დომენური ატომი), როდის=(ღუზა ერთხელ_k, ნიშანი F1:წინ)
სულ ეს არის. მეტი ტექსტში არ წერია — მეტი არ იბადება.
```

## IV. დასკვნა

1. ფუნდამენტური ქსელი მართლა ცოტაა: ამ ტექსტს **11 ეყო**, და ეჭვია, სხვა ტექსტები ამ რიცხვს ბევრს ვერ მოუმატებენ — დომენური მასალა იზრდება, წებო არა.
2. ყოველი F-ქსელი თავისი მესრის კანონით მოდის (რიგი/ბიჯი/ნული ან ტოპოლოგია) — ატომები შიგნით არ იყოფიან, პოზიციები ითვლება.
3. ბირთვს ემატება **ნული ცხრილი**: F-ქსელები თვითონ ველის მოქალაქეები არიან (ატომები nodes-ში, პოზიციები triples-ში), მესრის კანონი — ტოტის წესდების ხაზი.
4. დაშლის მანქანა: ჩარჩოს სტეკი (tbl) + ზმნის ნიშანი (F1-ვექტორი) + მოსავლის ჭერი (რაც არ წერია — არ იბადება) + F1–F11 წებო.
