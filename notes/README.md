## 1. რას ვაშენებთ

საერთო, მისამართებადი ცოდნის ველი, რომელსაც ადამიანიც კითხულობს და LLM-იც —
და რომელშიც ვერავინ (ვერც ადამიანი, ვერც მოდელი, ვერც ინსტიტუტი) ვერ აქცევს
თავის სურვილს ჩუმად ჭეშმარიტებად. უცოდინრობა ღირსეული, მისამართიანი
მდგომარეობაა (OPEN), სანამ პასუხი სერტიფიკატს არ დაიმსახურებს.

ფორმულა: **ენციკლოპედია ველში · გრამატიკა მოდელში · ხელოვნება ხალათში.**

## 2. რა უკვე დგას (აშენებული და გამოცდილი)

- **ბირთვი v2** — ერთი ლოგიკური მისამართების სივრცე, ორი ფიზიკური ცხრილი
  (nodes/triples), NULL = OPEN, ჰომოიკონურობა (ტრიპლეტი ტრიპლეტზე — META ტესტი მწვანე).
- **ველი ონლაინ** — noe.php googuly.online-ზე: dump/stats/get/find/batch/clear.
  ბრაუზერიდანაც მუშაობს, curl-ითაც, widget-იდანაც.
- **Car-wash სცენარი ველში** — პირველი აგებით-გადამოწმება: „ფეხით წავიდე?" → BLOCKED,
  დიფერენტი: car.location ≠ washing.requires.
- **AISocket Registry** — სამი მოქალაქე (c6-lcd-147, engineering-mentor, mobile-bridge),

- **Claude↔GPT საერთო ველის ცდა** — ორი სხვადასხვა ჰოლოგრამა ერთ ფოტოსურათზე;

## 3. კონცეპტუალური ხერხემალი (ბოლო დღეების მოსავალი)

### ასოები → სიტყვები → სიუჟეტი
ტრიპლეტები **ასოებია**. მოთხრობა Runner-ში იბადება, ველში კი — კვალი.
ველი ინახავს რა არის ჭეშმარიტი; გამშვები (მატრიცა/Runner) უშვებს რა მოხდება.

### აგებით გადამოწმება (დიფერენტი)
პასუხი მოწმდება არა პრეცედენტით, არამედ სცენის აგებით და მიზნის გატარებით.
დიფერენტი რეალურსა და აგებულს შორის — ერთადერთი პატიოსანი საზომი.
„მოდელმა იცის თავისი ცდომილება."

### კონდიციის კიბე K0–K9
ცოდნა არ ფასდება float-ით — ფასდება **გადამოწმებადი საფეხურით**:
K0 მისამართი არსებობს → K3 სერტიფიკატი განსაზღვრულია → K4 კანდიდატი ზის →
K6 ორი დამოუკიდებელი მოწმობა → K9 პროცედურად იქცა და ველი დატოვა.
კიბე თვითონ ტრიპლეტებად იწერება — გაფართოება = ჩამატება, ძრავა არ ეხება.

### ფიქრის ორგანოები (ბლოკ 1-ის ანატომია)
- **agenda** — ღია პოზიციები დავალებებად; ხვრელი თვითონ ითხოვს დახურვას
- **სვლები** — LOOKUP · BLOOM · DECOMPOSE · VERIFY, საწვავის ბიუჯეტით
- **თრედების სტეკი** — ფიქრი ანგარიშით ჩერდება (სად მივედი, რა დარჩა, რას ვაპირებდი)
  და კონდიციით ბრუნდება; დაბრუნება = bloom, განახლებულ ველზე
- **ვიგოტსკის ხაფანგები** — მაღვიძარები დროზე/ადგილზე/პირობაზე; გავლა ჰკრავს,
  თრედი იღვიძებს (აფთიაქის ეფექტი, Zeigarnik მექანიზმად)
- **needs-ჟურნალი** — რაც ველში ვერ დაეტია, ვექტორად იწერება; ჯიბე იკერება,
  როცა ერთ მიმართულებაზე საკმარისი ვექტორი დაგროვდა (კუტურიეს წესი)

## 4. ვანო-ნიკოს გაზომვა (პირველი რეალური ტვირთი)

ახვლედიანის ტექსტი დავშალეთ და ვზომეთ, რა აკლია ველს. ჯაჭვი ასე ჩამოიშალა:

**v0:** 12 მოთხოვნის ვექტორი → 5 დამოუკიდებელი ხვრელი
**v1:** ხვრელები ორვექტორიან ფორმაში (მდგომარეობის ხე × დროის ხე)
**v2:** ხელით აწყობა + მეორე გავლა → **12 ფუნდამენტური ქსელი, ~17 ატომი:**

> F1 რიგი · F2 ადგილი · F3 ზომა · F4 ნაწილი/მთელი · F5 იგივეობა · F6 მიზეზი ·
> F7 უარყოფა · F8 სურვილი · F9 ცოდნა · F10 შესაძლებლობა · F11 ხდომილება · F12 რაოდენობა
>
> (F13 კუთვნილება — OPEN: ჩინურმა გავლამ დაშალა, ქონა = ∃ + ღუზის არეში)

ფუნდამენტური ქსელი = **ატომები + მესრის კანონი**. ატომი შიგნით არ იყოფა —
მთელი მისი შინაარსი პოზიციაა (გუშინ = წინ-სა და ახლა-ს შორის, ბიჯი დღე,
მთელი რიცხვებით; „ნახევრად გუშინ" არ არსებობს). დომენური ხეები (განწყობები,
ადგილები) მასალაა; F-ქსელები — წებო. მასალა იზრდება, წებო არა.
თანასწორობის კრიტერიუმი: ატომები, რომლებიც ერთმანეთისგან არ იწყობიან,
ერთი ქსელის თანასწორი წევრები არიან. ქსელებს შორისაც არის კანონები
(იწვევს ⇒ წინ; დეიქტური სამკაუჭა აქ-ახლა-მე) — ეს კონსტიტუციის დონეა.

## 5. დეტერმინისტული წამკითხველი (დაშლის მანქანა)

ორი რეესტრი, სხვადასხვა კანონით:

- **ობიექტები — ღია კლასი:** ვერ იპოვე → დაბადე. იაფია, უვნებელი.
- **პრედიკატები — დახურული კლასი:** არასდროს იბადება კითხვისას. პრედიკატი
  შტეკერია F-ქსელებში: ლექსიკონიდან ამოღებისას თან მოათრევს **აღკაზმულობას**
  (ბუდეები: ვინ, სად, როდის...). შეუვსებელი ბუდე → OPEN, არა გამოგონება.

პლუს სამი წესი (ჩინური გავლით შესწორებული):
1. **ჩარჩოს სტეკი** — „ერთხელ" = ახალი tbl; ყველაფერი მასში იწერება შემდეგ ჩარჩომდე.
   თვითონ გამხსნელი კომპოზიტია: 有一天 = ∃ + ერთი + დღე.
2. **ზმნის ნიშანი** — ორი ბიტია: დროის მიმართულება (ღუზა, წინ/შემდეგ) და ცალკე
   **დასრულებულობა** (了/过). ჟურნალისთვის მეორე უფრო მნიშვნელოვანია.
3. **მოსავლის ჭერი** — რაც ტექსტში არ წერია, არ იბადება. ამომღები, რომელიც
   „ერთხელ ვანოს ეძინა"-დან ხუთ ჩანაწერზე მეტს აბრუნებს, იგონებს.

და ორი დაზუსტება: უარყოფის ოპერატორი ერთია, მაგრამ სამიზნის ტიპი ინიშნება —
F7(claim) ≠ F7(მოვლენა/არსებობა) (不/没; ემთხვევა kernel v2-ის ask()-ს);
სტატიკური პოზიცია და მოძრაობის ვექტორი ორი სვეტია (里 ≠ 进) — ინგლისური "in" ორივეს დნობს.
მოძრაობის ჩანაწერი აკორდია: ქმედება + მიმართულება + ჩემკენ/ჩემგან ბიტი;
სინონიმები ერთ addr-ზე იყრებიან, გაყინული მნიშვნელობები („მოაჯდა") — ლექსიკონის მეორე ფენაა.

### კარები (შესასვლელი ველები)
ობიექტების ხერხემალს მოდალობის ველები ებმის: სახელები, ხმა, სურათი... სახელი
პრივილეგირებული არ არის — ტექსტის მოდალობის სემპლია (kernel v2-ის D5 ამას
დამოუკიდებლად დაემთხვა). მეექვსე კარი — აზროვნების: იგივე მექანიზმი საკუთარ ნაკადს
უსმენს და addr-ზე რედუცირდება; აქ ებმის ჰოლოგრამა ველს. წესი: ყოველ ჩანაწერს აწერია,
რომელი კარიდან შემოვიდა (source). ჰალუცინაცია = აზროვნების კარის ჩანაწერი
დაკარგული წარმომავლობით. ჩაპლინის ტესტი: სცენა ერთი კარიდანაც აიგება —
კარები ურთიერთჩანაცვლებადია, ხერხემალი მოდალობის მიღმაა.

და თეორემა ლიტერატურაზე: **არც ერთი ნაწარმოები არ ამატებს ახალ პრედიკატს** —
ახალი ობიექტები, ძველი ბმები, ახალი პოზიციები. მეტაფორაც კი ძველი პრედიკატია
არასწორი ტიპის სტუმრით ბუდეში (ტიპის დარღვევა + პოეტური ხალათი = ხელოვნება;
იგივე claim-ფრეიმში = შეცდომა). ამიტომ ლექსიკონი ერთხელ იგება და ყველაფერს კითხულობს.

## 6. წესები, რომლებიც არ ირღვევა

- **აგება > შეთანხმება.** ლამაზად ჟღერს და სცენაზე ვერ დგება → არ მუშაობს.
- **თუ თვალი გაცდუნებს — განაგდე.** ნაადრევი დახურვა სოფისტის ბახილია.
- **მექანიზმი ≠ პოლიტიკა.** ძრავას ყველაფერი შეუძლია; ბაზას წესდება ზღუდავს (ჩანაწერი №0).
- **ნომრები ჯერ, სახელები მერე** (Leibniz-ის პატივსაცემად) — კლასიფიკაცია მასალის მერე.
- **ბახილების კანონი:** კვალი შესვლის პირობაა, არა ზნეობა. მისამართი აქვს ყველაფერს,
  ბიოგრაფია — მხოლოდ მოქმედს.
- **ველოსიპედი + კატაობა ერთად:** ყოველი ბლოკი ცოცხალ ტვირთზე მოწმდება, benchmark
  ცნობილი პასუხებით სტენდზე, გაურკვევლობა — გარეთ.
