# F-ქსელების ხელით აწყობა + მეორე გავლა ვანო-ნიკოზე (v2)

მეთოდი: ჯერ თითო ქსელი ავაწყვეთ ხელით — ატომები + მესრის კანონი — და ყოველ ატომს
დანა დავადეთ („შიგნით იყოფა?"). მერე „ერთხელ"-ის მოთხრობა თავიდან გავიარეთ
მზა ქსელებით: ვექტორი მიება → შემცირდა; ვერ მიება → ნაშთში ჩაიწერა.

## I. ქსელები, აწყობილი და დანაგამოვლილი

### F1 რიგი
```
ატომები: წინ · შემდეგ · ერთდროულად · [ღუზა: ახლა]
კანონი:  ხაზოვანი, ტრანზიტული; ბიჯი ტოტისაა (დღეები: დისკრეტული, მთელი)
```

### F2 ადგილი
```
ატომები: შიგნით · გარეთ · ესაზღვრება · [ღუზა: აქ]
კანონი:  ტოპოლოგია; შიგნით ტრანზიტულია; ზემოთ/ქვემოთ = მიმართული ღერძი ტოპოლოგიაზე
```
🔍 **აღმოჩენა აწყობისას:** ღუზა მეორდება — F1-ს აქვს „ახლა", F2-ს „აქ", პირებს „მე".
დეიქტური ნული ქსელის კი არა, **ქსელთაშორისი** კონსტრუქციაა: სამივე ერთი „აქ-ახლა-მე"
სამკაუჭას წვეროებია. ჩარჩო (tbl) სწორედ ამ სამკაუჭას აყენებს.

### F3 ზომა
```
ატომები: მეტი · ნაკლები · ტოლი
კანონი:  ხაზოვანი რიგი ნებისმიერ დომენურ ტოტზე; ყოველთვის სკალა-რეფერენტით
```

### F4 ნაწილი/მთელი
```
ატომი:   ნაწილია
კანონი:  ხე; ტრანზიტული; ციკლი აკრძალული. ჩადგმული სამყაროებიც ამით (ოცნება ⊃ სიზმარი)
```

### F5 იგივეობა
```
ატომები: იგივე · ჰგავს · ეგზემპლარია
კანონი:  იგივე = ეკვივალენტობა (ტრანზიტული); ჰგავს = სიმეტრიული, არა-ტრანზიტული(!);
         ეგზემპლარია = ბმა token→type (ჰაბიტუალური ნიმუშები ამით)
```
„სხვა" ამოვარდა: სხვა = F7(იგივე). ატომი არ ყოფილა.

### F6 მიზეზი
```
ატომი:   იწვევს
კანონი:  მიმართული, უციკლო + ქსელთაშორისი კანონი: იწვევს(a,b) ⇒ F1: a წინ b-ზე
```
🔍 **აღმოჩენა:** მესრის კანონები ქსელებს შორისაც არსებობს — მიზეზი დროის რიგს ავალდებულებს.

### F7 უარყოფა
```
ატომი:   არა
კანონი:  ოპერატორი ნებისმიერ ბმაზე; არა(არა(x))=x; არა ≠ OPEN (ვიცით-რომ-არა ≠ არ-ვიცით)
```

### F8 სურვილი
```
ატომი:   უნდა
კანონი:  აგენტი → მდგომარეობა; ჩვეულებრივ F1-მომავლისკენ იხრება
```
„არ-უნდა" ამოვარდა = F7(უნდა).

### F9 ცოდნა
```
ატომი:   იცის
კანონი:  აგენტი → addr (claim/მოვლენა)
```
„ახსოვს" ამოვარდა = იცის + ობიექტი-F1-წინ. „გაახსენდა" = მოხდა(იცის...) — F11+F9.

### F10 შესაძლებლობა
```
ატომი:   შესაძლებელია
კანონი:  სამყაროთა განშტოება; მოდალური ორადობა F7-ით:
         შეუძლებელია = არა(შესაძლებელია); აუცილებელია = არა(შესაძლებელია(არა))
```
🔍 სამი მოდალობიდან ატომი **ერთი** დარჩა — ორი F7-კომპოზიციით იშლება.

### F11 ხდომილება
```
ატომი:   მოხდა
კანონი:  ბადებს მოვლენა-ატომს; მოვლენას F1-პოზიცია სავალდებულო აქვს; უცვლელია
```

**შუალედური ჯამი:** დანამ ქსელი დააპატარავა — 11 ქსელში ატომი სულ **16 დარჩა**
(სხვა/არ-უნდა/შეუძლებელია/აუცილებელია/ახსოვს ყველა კომპოზიცია აღმოჩნდა),
ხოლო ორი ქსელთაშორისი კანონი გამოჩნდა: დეიქტური სამკაუჭა და მიზეზი⇒რიგი.

## III. ნაშთი — რა დარჩა, და ეს არის მოსავალი

**ნაშთი 1 — რაოდენობა. ახალი ფუნდამენტური ქსელი გამოჩნდა: F12.**
„ორივე", „უამრავი", „ათჯერ ათასამდე", „თითო-თითო ჭიქა", „ერთი იცინის, მეორე ტირის..."
— ტექსტი რიცხვებით არის გაჟღენთილი და 11 ქსელიდან ვერცერთს ვერ მიება:
```
F12 რაოდენობა:  ატომები: ერთი · ყველა · ზოგი   (ბევრი/ცოტა = F3 რაოდენობაზე;
                 არცერთი = F7(ზოგი); ორივე = ყველა(ორისგან))
                 კანონი: ნატურალური მესერი — თვლა; ის მესერი, რომელიც
                 „ნახევრად გუშინ"-ს კრძალავდა, თვითონ ქსელი აღმოჩნდა!
```

**ნაშთი 2 — კუთვნილება. მეორე კანდიდატი: F13.**
„**თავისი** გზა", „ვანოს ჰყავდა დედა", „**ჩემი** ფანჯარა", „**თავის** ბაღში" —
არც ნაწილია (დედა ვანოს ნაწილი არ არის), არც ადგილი:
```
F13 კუთვნილება:  ატომი: მისია/ეკუთვნის
                 კანონი: აგენტი → ობიექტი; ხე არა — ერთი ობიექტი ბევრს ვერ ეკუთვნის
                 ერთ ჭრილში (წესდების საკითხია)
```

**ნაშთი 3 — თქმის აქტი: ნახევრად იშლება.**
თქვა = F11-მოვლენა ტექსტი-ობიექტით ✅. მაგრამ „ჰკითხა" ≠ „თქვა":
კითხვა = თქვა + F8(უნდა, რომ F9(იცოდეს)) — იშლება, ოღონდ მძიმედ.
ჯერ ლექსიკონის აღკაზმულობად დავტოვოთ, ატომად ნუ ავწევთ. OPEN.

**ნაშთი 4 — ირონია: განზრახ გარეთ რჩება.**
მოთხრობის აზრი — ესკალაციის აბსურდი, სადაც დილის მისალმება საღამოს ჩხუბს შობს —
არცერთ ქსელში არ ზის და **არ უნდა იჯდეს**: ის მკითხველის ინტერპრეტანტია, ხალათის
შრე. ველი ინახავს სცენებს; ღიმილი მკითხველში იბადება. OPEN-BY-DESIGN.

## IV. გაკვეთილი

1. ხელით აწყობამ ქსელი ორივე მხარეს შეასწორა: ატომები **შემცირდა** (16-მდე —
   F7-კომპოზიციები გამოიჭრა), ქსელები **გაიზარდა** (F12 რაოდენობა, F13 კუთვნილება —
   მხოლოდ მეორე გავლამ გამოაჩინა). წინასწარ ვერც ერთს ვერ ვიტყოდით — აგება > შეთანხმება.
2. ქსელთაშორისი კანონები არსებობს (მიზეზი⇒რიგი; დეიქტური სამკაუჭა აქ-ახლა-მე) —
   ეს ტოტის წესდებაზე მაღლა დგას, ველის კონსტიტუციის დონეა.
3. ნამდვილი ნაშთი ორი სახისაა: **დასაბადებელი ქსელი** (F12, F13 — წესდების გზით)
   და **განზრახ დაუბადებელი** (ირონია — ხალათს რჩება). ამ ორის გარჩევა თვითონ
   არის სისტემის სიჯანსაღის ნიშანი.
